A one-image summary of the world's news on Friday 27 November 2026,
drawn by a Python program (standard library only) as a 1024x1024 PNG.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes `out/entry.png`. Run it twice and the two files are byte-identical.
